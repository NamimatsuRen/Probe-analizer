# ADR 0002: JSONではなくフォルダを入力境界にする

- Status: Accepted
- Date: 2026-07-23

## Context

旧コードはJSONに日付、shot、raw/sweep basename、解析範囲を列挙してから起動していた。これはデータを「まず見る」段階にも解析設定の準備を要求し、フォルダ選択中心の操作と合わない。

## Decision

Level 1の入力はフォルダだけにする。同名の `.hdr` と波形を自動検出し、系列一覧を作る。

チャンネル役割、倍率、解析範囲などの解析設定はフォルダ走査から分離する。Level 2以降で、画面上の選択と再現可能な設定保存として追加する。

## Consequences

- JSONを作らなくてもRawデータへ到達できる。
- 未知チャンネルも消さずに一覧へ出せる。
- basenameの意味を自動断定しないため、Level 2で役割割当UIが必要になる。
- 旧JSONは将来「移行インポート」として追加できるが、通常起動の必須入力には戻さない。
