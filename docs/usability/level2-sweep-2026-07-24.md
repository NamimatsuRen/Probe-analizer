# Level 2 Sweep対応理解テスト

実施日: 2026-07-24  
方式: 内部エキスパート・ウォークスルー + 自動E2E照合  
参加者: 1名相当（開発時の内部確認）

## タスク

1. 指定されたSweepへ、一覧または前／次操作で移動する。
2. 選択SweepがRaw時系列のどの時間・sample範囲に対応するか回答する。
3. 選択Sweepが上昇・下降のどちらか回答し、I–V表示の始点・終点を確認する。

## 判定基準

| 指標 | 成功条件 |
|---|---|
| 指定Sweep到達 | 一覧・現在位置・選択IDが指定Sweepと一致 |
| Raw上位置 | orange highlight、時間範囲、source sample範囲が一致 |
| 方向理解 | 一覧の矢印、Raw説明、I–V説明が同じ方向 |

## 結果

| タスク | 成功数 / 試行数 | 成功率 | 根拠 |
|---|---:|---:|---|
| 指定Sweep到達 | 3 / 3 | 100% | 一覧選択、次、前の3経路 |
| Raw上位置 | 3 / 3 | 100% | 時間区間・sample範囲をgolden値と照合 |
| 方向理解 | 3 / 3 | 100% | 矢印、説明文、取得始点／終点を照合 |

自動照合は`tests/e2e/test_level1_window.py`で、選択ID、Raw highlight、I–V配列、方向、端点、
上位選択変更後の消去を固定している。

## 発見事項

- 現在位置`n / total`と前／次ボタンにより、指定Sweepへ到達する経路が明確になった。
- RawとI–Vの説明に同じSweep IDと方向が出るため、対応を照合できる。
- 除外区間はvalid Sweep一覧と分けて表示され、誤って解析対象として選択できない。

## 制約と次の確認

これは内部1名相当のベースラインであり、初見利用者3〜5名の統計的な利用テストではない。
実利用者テストでは同じ3タスクを説明なしで実施し、迷った箇所、完了時間、誤答理由を追記する。
この制約はLevel 2コードの機能完了を妨げないが、UIの外部妥当性として別途追跡する。
