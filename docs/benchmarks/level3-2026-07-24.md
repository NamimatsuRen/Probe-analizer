# Level 3 preprocessing benchmark — 2026-07-24

## 条件

- macOS / Apple Silicon
- Python 3.13.14
- NumPy 2.4.3
- SciPy 1.18.0
- 10,000点の1 Sweep
- SG窓501点、3次
- warm-up後100回

## コマンド

```bash
uv run python scripts/benchmark_preprocessing.py \
  --points 10000 --repeat 100 --window 501
```

## 結果

| 指標 | 時間 |
|---|---:|
| median | 2.181 ms |
| p95 | 2.265 ms |
| max | 2.362 ms |

Level 2のSweep切替目標200 msに対して十分小さい。選択中1 Sweepだけを処理するため、
現時点ではGUIスレッド内の同期計算とする。将来、点数・窓・同時計算方式が大きくなり、
実測が50 msを継続的に超える場合はbackground worker化を再検討する。
